## Little Lemon

## Little Lemon is a restaurant that serves a variety of dishes. They have a mobile app that allows customers to place orders online and track their orders in real-time. This project is a React Native app that allows customers to sign up for the newsletter and subscribe to the app.

## Installation

1. Download the project and unzip it

2. Install dependencies

```bash
npm install
```

3. Start the app

```bash
npm start
```

4. Open the app on your phone
